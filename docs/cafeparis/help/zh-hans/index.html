1€ le Café

帮助与常见问题

最后更新：2026年11月25日

「1€ le Café」收录了巴黎那些一杯咖啡仍然只要 1 欧元的咖啡馆，支持 iPhone、iPad 和 Android。没有找到你的问题？请发送邮件至 contact@nagord.com。

这个应用是做什么的？

帮你在巴黎找到附近 1 欧元一杯的咖啡。咖啡馆会显示在地图和列表中：开启定位时按步行时间排序，否则按区排列。每家咖啡馆都会标明条件（吧台站着喝、外带等）和优惠时段，还可以直接查看路线。

地址是从哪里来的？

来自托管在 Framacarte 上的协作地图“Cafés à 1 €”，由 paris.fr 的读者和社交网络上的网友共同补充。在应用的“关于”页面中，点按“查看原始地图”即可打开这张地图。

价格或条件对不上

这些信息来自协作地图，价格、时段或条件可能已经有所变化。最简单的办法是点单前先在吧台问一下。

“现在有效”是什么意思？

这个筛选条件只显示此刻 1 欧元优惠仍然有效的咖啡馆。它始终以巴黎时间为准，即使你的手机设置在其他时区。

为什么应用会请求我的位置？

仅用于将咖啡馆按由近到远排序并估算步行时间。计算在手机上完成，你的位置不会发送给任何人。是否允许由你决定；不开启定位时，咖啡馆会按区排列。

如何开启或关闭定位？

  • iPhone 和 iPad：设置 > 1€ le Café > 位置，然后选择在使用应用期间允许，或永不允许。
  • Android：设置 > 应用 > 1€ le Café > 权限 > 位置信息（具体名称可能因手机品牌而异）。

定位关闭时，应用内也会显示一个“设置”按钮，可直接跳转到对应页面。

可以离线使用吗？

可以。咖啡馆列表内置在应用中，每次在联网状态下启动时都会更新。没有网络时，应用会显示现有的列表，并标注“离线”；此时底图可能显示不完整。

我的集章卡保存在哪里？

集章卡记录你盖过章的咖啡馆。它只保存在你的手机上，不会发送到任何服务器，删除应用后即被清除。

反馈咖啡馆已关门或价格有变

请发送邮件至 contact@nagord.com，注明咖啡馆的名称、地址以及变化情况。谢谢，这对大家都有帮助。

我的数据呢？

「1€ le Café」不收集任何个人数据。详细内容请参阅隐私政策。
