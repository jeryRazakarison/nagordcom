1€ le Café

ヘルプとよくある質問

最終更新日：2026年11月25日

「1€ le Café」は、エスプレッソがいまも1ユーロで飲めるパリのカフェをまとめたアプリです。iPhone・iPad・Android で利用できます。ここにない質問は contact@nagord.com までお送りください。

どんなアプリですか？

パリで近くの1ユーロコーヒーを見つけるためのアプリです。カフェは地図とリストで表示され、位置情報をオンにしていれば徒歩時間の短い順、オフなら区ごとに並びます。各カフェでは条件（カウンターのみ、テイクアウトなど）やオファーの時間帯を確認でき、経路を表示することもできます。

住所はどこから来ていますか？

Framacarte 上の共同編集地図「Cafés à 1 €」からです。この地図は paris.fr の読者や SNS からの情報で更新されています。アプリの「このアプリについて」にある「元の地図を開く」から、この地図を見られます。

値段や条件が違っていました

情報は共同編集の地図に基づいているため、値段や時間帯、条件が変わっている場合があります。注文する前にカウンターで確かめるのがいちばん確実です。

「今すぐOK」とは何ですか？

いまの時間に1ユーロのオファーが有効なカフェだけを表示するフィルターです。端末のタイムゾーンが別の地域に設定されていても、判定には常にパリの時刻を使います。

なぜ位置情報を求められるのですか？

カフェを近い順に並べ、徒歩時間を見積もるためだけです。計算は端末上で行われ、位置情報が誰かに送信されることはありません。許可は任意で、許可しない場合はカフェが区ごとに並びます。

位置情報のオン・オフはどうすればいいですか？

  • iPhone・iPad：設定 > 1€ le Café > 位置情報 で、アプリの使用中に許可するか、許可しないかを選びます。
  • Android：設定 > アプリ > 1€ le Café > 権限 > 位置情報（表示名はメーカーによって異なる場合があります）。

位置情報がオフのときは、アプリ内にも該当画面へ移動できる「設定」ボタンが表示されます。

オフラインでも使えますか？

はい。カフェのリストはアプリに内蔵されており、起動時にネットに接続できれば最新の内容に更新されます。オフラインのときは手元のリストを表示し、「オフライン」と表示されます。その場合、背景の地図は一部しか表示されないことがあります。

スタンプカードはどこに保存されますか？

スタンプカードには、スタンプを押したカフェが記録されます。保存先はあなたの端末の中だけで、サーバーには送信されません。アプリを削除すると消去されます。

閉店したカフェや値段の変更を知らせたい

カフェの名前と住所、変わった点を書いて contact@nagord.com までメールしてください。みんなの役に立ちます。ありがとうございます。

データの扱いは？

「1€ le Café」は個人データを一切収集しません。詳しくはプライバシーポリシーをご覧ください。
