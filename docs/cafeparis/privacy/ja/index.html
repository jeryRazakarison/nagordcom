1€ le Café

プライバシーポリシー

最終更新日：2026年11月25日

「1€ le Café」は個人データを一切収集しません。アカウント、広告、利用統計、トラッキングはありません。位置情報を許可した場合も、その利用は端末の中だけで完結し、スタンプカードも端末内に保存されます。

提供者

「1€ le Café」は、Nagord（Jery Razakarison）が提供する iPhone・iPad・Android 向けアプリです。本ポリシーに関するお問い合わせは contact@nagord.com までメールでお送りください。

このアプリが行わないこと

  • アカウント作成や会員登録はありません。
  • 広告はありません。
  • 利用統計の収集やトラッキングは行いません。
  • 解析やクラッシュレポートの SDK は組み込んでいません。
  • データを販売したり、第三者と共有したりすることはありません。

位置情報

アプリは、使用中に限って位置情報へのアクセスを求めることがあります。許可するかどうかは任意です。

  • 位置情報は、カフェを近い順に並べ、徒歩でかかる時間を見積もるためだけに使います。
  • この計算は端末上で行われ、位置情報が Nagord や第三者に送信されることはありません。
  • 位置情報を許可しなくてもアプリはそのまま使え、カフェは区（アロンディスマン）ごとに表示されます。
  • 許可はいつでも端末の「設定」（iPhone・iPad・Android）から取り消せます。

スタンプカードと設定

スタンプカード（すでに「飲んだ」カフェの記録）とアプリの設定は、端末の中だけに保存されます。どこにも送信されず、アプリを削除すると消去されます。

ネットワーク通信

アプリは起動時に、共同編集の uMap 地図「Cafés à 1 €」を公開している framacarte.org から、カフェの公開リストをダウンロードします。この通信に個人データは含まれません。ただし一般的なウェブ通信と同じく、サーバー側には接続元の IP アドレスが見えます。

背景の地図は端末によって異なります。

  • iPhone・iPad では Apple のマップ（MapKit）を使用し、Apple のプライバシーポリシーが適用されます。
  • Android では OpenFreeMap（openfreemap.org）の地図タイルを使用します。OpenFreeMap が受け取るのは IP アドレスと表示中の地図の範囲で、あなたの現在地は送信されません。

経路と共有

「経路」ボタンを押すと、端末の地図アプリ（iPhone ではマップ、Android では Google マップ）が開きます。「共有」ボタンを押すと、システムの共有シートが開きます。いずれもあなたが操作したときにだけ動作し、その先で選んだアプリがどう処理するかは、そのアプリのプライバシーポリシーに従います。

お子さまについて

本アプリは 13 歳未満のお子さまを対象としていません。

あなたの権利

EU 一般データ保護規則（GDPR）は、個人データへのアクセスや削除を求める権利などを定めています。「1€ le Café」は個人データを収集しないため、Nagord がサーバー上で開示・削除できるデータはありません。アプリが保存する情報は、すべてあなたの端末の中にあります。ご不明な点は contact@nagord.com までお問い合わせください。

本ポリシーの変更

データの取り扱いに影響するような変更がアプリに加わった場合は、新しい日付とともにこのページを更新します。
